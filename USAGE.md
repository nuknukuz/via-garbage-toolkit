# Инструкция пользователя

## 0. Установка (один раз)

1. **Python-часть** (нужен Python 3.8+):
   ```powershell
   python -m pip install opencv-python-headless numpy
   ```
   Важно: именно `opencv-python-headless` — обычный `opencv-python` требует системную libGL. На Linux при `externally-managed-environment`: `python3 -m venv venv && source venv/bin/activate` и ставить туда.

2. **VIA локально**: скачай дистрибутив VIA 2.x (via.html). Расширение не работает с онлайн-версией на сайте VGG.

3. **Подключить расширение**: положи `patch_via.py` и `via_group_transform.js` рядом с `via.html`, затем
   ```powershell
   python patch_via.py via.html
   ```
   Создаётся бэкап `via.html.bak`. Проверка: перезагрузи страницу (Ctrl+F5) — в статусной строке внизу появится «GT v2.3: B — рамка выделения, G — перенос, …». Если обновлял `via_group_transform.js` — обязателен Ctrl+F5 (жёсткое обновление без кэша).

## 1. Ежедневный цикл разметки пака

Все команды — **одной строкой** (PowerShell не понимает `\`-перенос; для переноса используй обратный апостроф `` ` ``).

### Шаг 1. Планирование

```powershell
python via_propagate.py pack_014.json --plan plan14.json --root . --edges-csv edges14.csv
```

- `--root .` — папка с кадрами; если путь из JSON доступен (NAS), можно не указывать.
- Скрипт построит словарь признаков (1–2 мин на 200 кадров), покажет разбиение на кластеры и спросит `Разделение на кластеры норм? [Y/n]`.
  - `y` (или Enter) — принять.
  - `n` — ввести границы вручную: `2685-2730,2731-2912` (номера кадров из имён файлов).
- Дальше скрипт предложит 2–5 кадров на кластер под ручную разметку и сохранит `plan14.json` + `plan14_donors.txt`.
- Кластеры из 1–2 кадров (хвосты серий, разрывы нумерации) предложатся к разметке целиком — внутри них переносить некуда, это нормально.

### Шаг 2. Ручная разметка доноров

В VIA открой проект, разметь кадры из `plan14_donors.txt` (горячие клавиши — ниже, они сильно ускоряют), затем **Project → Save**.

### Шаг 3. Применение

```powershell
python via_propagate.py pack_014_saved.json --use-plan plan14.json --root . --out pack_014_filled.json --draw previews14 --report rep14.csv
```

- Цели = все кадры кластеров, кроме доноров. **Старая разметка на целях заменяется** перенесённой (скрипт напечатает, у скольких целей она была). Входной JSON не меняется.
- Следи за колонкой статусов: `ok` — хорошо; `few_matches`/`low_inliers` — матчинг не сошёлся; `no_source_in_cluster` — в кластере нет размеченного донора.
- `previews14/` — уменьшенные кадры с нарисованными боксами для быстрой проверки глазами.

Вариант «сумма доноров» — на цель переносится объединение боксов со ВСЕХ размеченных доноров кластера (каждый донор матчится отдельно), а дубликаты схлопываются:

```powershell
python via_propagate.py pack_014_saved.json --use-plan plan14.json --root . --out pack_014_filled.json --merge-donors --dup-overlap 0.65 --draw previews14 --report rep14.csv
```

- Если ≥ `--dup-overlap` (дефолт 0.65) площади перенесённого бокса накрыто уже оставленным боксом с ДРУГОГО донора — бокс выбрасывается; выживает бокс с донора, у которого больше совпадений дескрипторов с целью.
- Боксы, перекрывающиеся внутри одного донора, не трогаются — соседние объекты на одном кадре это норма.
- В отчёте: `method=multi(2/3)` — сколько доноров успешно сматчилось из всех; статус `ok_partial` — часть доноров не сошлась (боксы с остальных всё равно перенесены); колонка `dedup_dropped` — сколько дублей выброшено.
- Ограничение `--max-dist` в этом режиме не действует: доноры заданы явно, качество каждой пары контролируют `--min-inliers` / `--min-inlier-ratio`.

### Шаг 4. Дожимка в VIA

Открой `pack_014_filled.json`, пройди по целям, подгони группы клавишами (см. ниже), сохрани проект.

### Резервный режим (план потерян / терминал слетел)

```powershell
python via_propagate.py pack_014_saved.json --clusters "2685-2730,2731-2912" --donors "garbage.0002690.jpg,garbage.0002738.jpg" --root . --out filled.json
```

Ровно так же работает ручной сценарий «вбить интервал + размеченные кадры вручную»; добавь `--merge-donors`, чтобы цель получала сумму боксов со всех перечисленных доноров.

## 2. Горячие клавиши расширения (VIA)

Работают в любой раскладке (по физической клавише), когда фокус не в текстовом поле. Применяются **только к выделенным** боксам. При старте режима в статусной строке видно, сколько боксов захвачено («Режим grab: N бокс(ов)») — сверяйся с ней, если результат неожиданный.

| Клавиши | Действие |
|---|---|
| `B` | Выделение рамкой (бокс захвачен, если его граница пересекает область); `Shift+B` — добавить к выделению |
| `G` + мышь | Перенос за курсором; `X`/`Y` по ходу — только по горизонтали/вертикали |
| `S` + мышь | Масштаб вокруг общего центра масс; `X`/`Y` — по одной оси |
| `S` в режиме | Переключить «вокруг центра каждого бокса» (аналог SS) |
| `R` + мышь | Поворот центров вокруг общего центра масс |
| `R` в режиме поворота | Каждый бокс на 90° вокруг своего центра (обмен ширины/высоты) |
| `R`+`X` / `R`+`Y` | 3D-наклон вокруг горизонтальной/вертикальной оси через центр масс |
| `Q` / `E` | Шаговый поворот ±3° (с Shift — ±0.5°) |
| `-` / `=` | Шаговый масштаб группы ∓5% (с Shift — 1%) |
| `[` / `]` | Сила перспективы для наклонов (дистанция D) |
| `Z` (или `U`) | Откат последней GT-операции |
| `X` вне режима | Отключён (штатное действие VIA сбивало с толку); `X`/`Y` работают как выбор оси внутри режимов |
| `Esc` | В режиме — отмена; вне режима — снять GT-выделение |
| `` ` `` | Диагностика в статусную строку (см. траблшутинг) |
| `Alt`+drag | Перенос группы мышью |

Модальные режимы: **ЛКМ/Enter — применить, Esc/ПКМ/Z — отмена**. Штатные клавиши VIA (`a/c/v/d`, стрелки) не перехватываются.

## 3. Параметры via_propagate.py (когда крутить)

| Флаг | Дефолт | Когда менять |
|---|---|---|
| `--min-edge-matches` | 25 | Кластеры дробятся → уменьшить (10); склеиваются → увеличить |
| `--cut-abs` | 0.55 | Абсолютный порог сигнатурного расстояния; склеивает зиму/лето → уменьшить (0.4) |
| `--cut-k` | 4.0 | Множитель MAD для адаптивного порога сигнатур |
| `--donors-per-cluster` | авто (2–5) | Зафиксировать число доноров на кластер |
| `--merge-donors` | выкл | Переносить сумму боксов со всех доноров кластера, а не с одного лучшего |
| `--dup-overlap` | 0.65 | Порог дубликата при сумме доноров. Остаются дубли → опустить (0.5); пропадают разные объекты рядом → поднять (0.75) |
| `--min-inliers` / `--min-inlier-ratio` | 12 / 0.25 | Тёмные/однотонные кадры не матчатся → 8 / 0.15 |
| `--max-dist` | 8 | Макс. дистанция цель↔донор в кадрах (в режиме `--merge-donors` не действует) |
| `--targets-mode` | auto | `empty` = только совсем пустые; `nondonors` = все кроме доноров |
| `--sig-feats` | 2500 | ORB-фич на кадр в словаре |
| `--dry` | — | Только отчёт, JSON не писать |

## 4. Траблшутинг

- **Клавиши расширения не работают.** 1) Ctrl+F5 (кэш браузера: имя файла то же). 2) Кликни по картинке, чтобы фокус был на канвасе. 3) Нажми `` ` `` (бэктик, слева от 1): в статусной строке появится `GT diag: image_id=… | regions=… | via_sel=[…] | gt_sel=… | canvas=ok … | via_scale=… | R=…`. Если `canvas=MISSING` или `…=undefined` — пришли эту строку разработчику (или автору расширения), это несовместимость версии VIA. 4) F12 → Console: красные ошибки при нажатии клавиш — тоже прислать.
- **«Ничего не выделено» при G/S/R.** Сначала выдели: `B` рамкой или штатно (`A` — все, клик по боксу).
- **B выделяет не те боксы / двигаются все боксы сразу.** Должно быть починено в v2.3 (пересчёт координат мыши больше не зависит от `_via_canvas_scale`). Обнови `via_group_transform.js`, переподключи (`python patch_via.py via.html` для однофайловой сборки), Ctrl+F5. Если повторяется — нажми `` ` `` и пришли строку диагностики: в ней теперь видны `R` (эмпирический масштаб) и список `via_sel`.
- **На целях дубли одних и тех же объектов** — включи `--merge-donors` или понизь `--dup-overlap` (0.5). **Пропадают близкие, но разные объекты** — повысь `--dup-overlap` до 0.7–0.75.
- **PowerShell падает с «Отсутствует выражение после унарного оператора "--"»** — команда набрана с `\`-переносами строк; пиши одной строкой. И вызывай `python`, не `python3` (на Windows `python3` — заглушка Microsoft Store).
- **`libGL.so.1: cannot open shared object`** — стоит не тот пакет: `pip uninstall opencv-python && pip install opencv-python-headless`.
- **`no_image` в отчёте** — кадры не найдены: проверь `--root` и кавычки вокруг путей с кириллицей/пробелами.
- **Кластеры склеили разные локации/сезоны** — ужесточи: `--cut-abs 0.45 --min-edge-matches 35`, либо на вопросе ответь `n` и введи границы вручную. Обратно (дробится слишком мелко): `--cut-abs 0.7 --min-edge-matches 10`.
- **«ВНИМАНИЕ: донор … не размечен»** — разметь его в VIA и пересохрани проект, иначе кластер останется без источника.
- **Качество переноса проверять сначала по `previews*/`**, потом в VIA; системные промахи по `dm=`/`inliers` в `rep*.csv`.
